# tools/

Developer tooling for the Nuvio Tizen app. Nothing in this folder ships in the WGT: `scripts/package-tizen.mjs` packages only `dist/` and `services/`.

- `html-color-probe/`: standalone Tizen 4 widget that tests whether HTML video frames can be read back into a canvas (the ambilight research question). Build and install it separately; see its README.
